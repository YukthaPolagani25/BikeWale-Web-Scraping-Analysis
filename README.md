
# BikeWale Bike Market Analysis

## Project Overview
This project analyzes bike data collected from the BikeWale website using web scraping, Regular Expressions and Python.

## Technologies Used
- Python
- BeautifulSoup
- Regular Expressions (Regex)
- Pandas
- NumPy
- Matplotlib

## Project Workflow
1. Web Scraping
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Business Insights

## Key Features
- Bike price and rating analysis
- Mileage and power comparison
- Correlation analysis
- Project-defined bike comparison scores

## Limitations
The dataset represents a limited sample of bikes collected from the website. Website data may change over time.
